## Воспроизводимость

Расчёт SUS и сводной статистики выполнен скриптами Python 3 без внешних библиотек:

```bash
python3 scripts/calculate_sus.py
python3 scripts/summarize_usability.py
python3 scripts/calculate_sus.py --self-test
```

Скрипты читают JSON из каталога `data`. Полные сводки сохранены в [расчёте SUS](data/sus-summary.json) и [сводке заданий](data/usability-summary.json).
