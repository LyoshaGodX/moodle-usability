# Протокол фактической проверки и происхождение изображений

[К оглавлению](../README.md)

Дата проверки: **05.10.2026**. Среда: живой Moodle РГПУ им. А. И. Герцена, настольный Chrome, русская версия интерфейса, доступ студента к указанному курсу.

Формат — экспертное прохождение. Участники не привлекались, время и число ошибочных переходов этого прохождения не фиксировались. Модельные результаты находятся отдельно в каталоге `data`.

## Предоставленные исходные страницы

До доступа к живому Moodle были изучены две сохранённые страницы: курс и форум. Их структура сверена с текущим интерфейсом. Названия и контрольные суммы находятся в [sources.json](sources.json).

Сохранённые HTML-файлы не распространяются вместе с отчётами: они содержат служебные параметры сеанса и не нужны для чтения README. Учётные данные не включены ни в протокол, ни в изображения.
